参数 说明

创建表

参数 说明
int 整数
not null 不能为空
auto_increment 自增
primary key 主键
varchar(20) 字符串长度为20
id name age 字段名

插入数据

参数 说明
user 表名
name 字段名
age 字段名
values 值
(‘张三’, 18) 值

values 后面括号中的值要和字段名一一对应
